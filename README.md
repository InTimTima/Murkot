# Murkot

**Murkot** — CIS IT-площадка, чтобы найти команду, проект или людей в стартап. Чаты внутри — чтобы договориться, а не как отдельный продукт.

## Что внутри

- **Доска** — объявления, витрина проектов, матч по карточкам, сообщества
- **Чаты** — личные, группы и каналы
- **Профиль** — карточка разработчика, заметка «зачем я здесь»

## Запуск

```bash
flutter pub get
flutter run -d chrome
# или
flutter run -d web-server --web-port 8080
```

Supabase-миграции лежат в `supabase/features_v*.sql` — применяются в SQL Editor проекта.
